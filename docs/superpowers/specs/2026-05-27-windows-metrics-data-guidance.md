# Windows Metrics Data Guidance Design

## Context

VoiceInk for Windows records local session metrics for recorder, file transcription, retry, transcription provider/model, enhancement provider/model, words, audio duration, keystrokes saved, and estimated time saved. The Metrics page already shows cards, filters, action rows, diagnostics rows, model performance rows, CSV export, and reset.

Privacy-first Windows analytics products commonly make clear what is counted, where it lives, and what export/reset affects. VoiceInk should do the same without adding telemetry.

## Goal

Add presenter-backed data guidance rows to the Metrics page:

- sessions and words come from local completed VoiceInk work;
- words per minute derives from words and audio duration;
- keystrokes/time saved are local estimates;
- CSV export/reset affect metrics data only.

## Non-Goals

- No formula changes.
- No remote analytics.
- No new metric storage tables.
- No dependency changes.

## Testability

Rows are generated by `SessionMetricsDashboardPresenter` and rendered read-only by WinUI, so behavior is covered by Core presenter tests.
