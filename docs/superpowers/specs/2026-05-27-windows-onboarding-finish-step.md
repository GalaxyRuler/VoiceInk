# Windows Onboarding Finish Step Design

## Context

The Windows onboarding dialog already walks users through model selection, microphone readiness, shortcut setup, and the first recording gesture. It stops immediately after insertion, while first-run dictation guidance usually closes the loop by telling users to verify the inserted text and where to recover/retry if needed.

## Goal

Add a final tutorial row to onboarding:

- verify the transcript appears in the focused field;
- use History to review, paste, retry, or recover the last dictation.

## Non-Goals

- No new onboarding window.
- No new settings schema.
- No commercial account/signup prompts.

## Testability

The final step is generated by `OnboardingChecklistPresenter` and covered by existing onboarding presenter tests.
