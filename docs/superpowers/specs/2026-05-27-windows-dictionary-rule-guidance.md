# Windows Dictionary Rule Guidance Design

## Context

VoiceInk for Windows supports vocabulary words, word replacements, quick add, local import/export, and replacement cleanup in the transcription pipeline. Dictation apps commonly surface dictionary guidance because users rely on it for names, product terms, technical jargon, and repeated misrecognitions.

The Dictionary page shows counts and row details, but it does not summarize the rule application order in a scan-friendly way.

## Goal

Add presenter-backed rule guidance rows to the Dictionary page:

- vocabulary helps prompts recognize names and terms;
- enabled replacements run after transcription and before insertion;
- disabled replacements stay saved but are skipped;
- import/export uses local JSON and does not sync automatically.

## Non-Goals

- No new replacement engine behavior.
- No regex support in this slice.
- No cloud sync or account flow.
- No dependency changes.

## Testability

Rows are generated by `DictionaryPagePresenter` and rendered read-only by WinUI, so behavior is covered by Core presenter tests.
