# Windows Onboarding Tutorial Steps Design

## Context

The macOS VoiceInk onboarding ends with a "Try It Out" screen that walks through a first dictation: click a text area, press the configured shortcut, speak, then press the shortcut again to insert text.

The Windows onboarding already covers model selection, microphone health, shortcut setup, setup actions, readiness summary rows, and setup stages. The first dictation smoke path is currently compressed into summary text instead of a dedicated tutorial sequence.

## Goal

Add presenter-backed tutorial step rows to the Windows onboarding flow so the first-run dialog mirrors the original try-it-out workflow more closely.

## UX

The first-run dialog shows four tutorial steps after the setup stages:

1. Click a focused text field.
2. Press the configured primary shortcut.
3. Speak a short phrase.
4. Press the shortcut again to stop and insert text.

When required setup is incomplete, rows are marked as waiting. When model, shortcut, and microphone are ready, rows are marked ready.

## Non-Goals

- No fragile UI automation of a tutorial text editor.
- No microphone recording inside the dialog itself.
- No new shortcut registration behavior.

## Testability

Tutorial rows are generated by `OnboardingChecklistPresenter`, so wording and readiness state are tested without WinUI automation.
