# Windows Settings Backup Guidance Design

## Context

VoiceInk for Windows already exports and imports local settings backups with category selection, dictionary data, custom prompts, Power Mode rules, imported model references, and sanitized provider endpoints. Provider API keys remain in Windows Credential Manager and are not written to backup JSON.

The Settings page currently states the no-secrets rule, but it does not summarize the backup categories in the same scan-friendly style as other settings summaries.

## Goal

Add presenter-backed backup guidance rows to the Settings page so users can see:

- which categories are included in settings backup;
- that provider API keys stay local;
- that custom model entries are references, not copied model binaries;
- that dictionary data can be exported/imported separately.

## Non-Goals

- No change to backup JSON schema.
- No credential export.
- No automatic cloud sync.
- No dependency changes.

## Testability

Rows are generated by `SettingsSectionPresenter` and rendered by WinUI as read-only guidance, so behavior is covered by Core presenter tests.
