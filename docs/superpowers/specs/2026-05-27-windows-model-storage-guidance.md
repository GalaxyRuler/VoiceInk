# Windows Model Storage Guidance Design

## Context

VoiceInk for Windows supports local whisper.cpp GGML model downloads into app-local storage and imported `.bin` model references from user-chosen paths. Windows guidance treats large local-only data as local app data, while user-selected files should remain under user control through picker-backed access.

The AI Models page shows model availability and actions, but it does not summarize where model files live, what import means, whether backups copy model binaries, or how warmup behaves.

## Goal

Add presenter-backed storage guidance rows to the AI Models page:

- downloaded catalog models are stored under the app-local Models folder;
- imported models remain user-owned file references;
- settings backup stores references and not large model binaries;
- warmup loads the selected local model to reduce first-use delay.

## Non-Goals

- No new model download source.
- No automatic file move/copy for imported models.
- No backup schema changes.
- No dependency changes.

## Testability

Rows are generated by `ModelLibraryOverviewPresenter` and rendered read-only by WinUI, so behavior is covered by Core presenter tests.
